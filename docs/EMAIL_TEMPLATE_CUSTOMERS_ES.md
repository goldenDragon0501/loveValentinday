## Notas para el administrador

- El enlace de acceso se genera en el panel de administración: pestaña **Clientes** > **+ Registrar cliente** o **Generar nuevo enlace**
- Usa el botón **Copiar** para copiar el enlace antes de pegarlo en este correo
- Si el cliente pierde su enlace, puedes generar uno nuevo desde el panel (el anterior se desactiva automáticamente)
- También puedes enviar el enlace por WhatsApp directamente desde el panel
